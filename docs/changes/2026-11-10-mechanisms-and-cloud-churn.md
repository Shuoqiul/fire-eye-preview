# 机制响应、区域配色与固定中心云图

## 本轮范围

按确认，仅同步 `fire-eye-preview` 的 `main` / `dev` 分支。`PROJECT_STATUS.md` 仍作长期 memory，本轮交付记录集中在此文件。

共同界面更新：降水用更深的蓝色，雷暴用紫色，烧除用更透明的深红色。高风宽度滑条为完整横向宽度 20–200 km，默认 100 km；沿线长度仍来自绘制路径。横向箭头固定屏幕间距，改变宽度添加/移除行，不把原有行拉稀。拐弯重叠只合成方向，再归一化至局部风速；重叠条数不会把风速放大。

红色烧除选区和蓝色减小差值原本是两个叠加层。现在结果视图隐藏事件色块，Change 视图也隐藏基线热图，保留统一的“蓝色降低 / 红色升高”差值语义。烧除响应另有逐格不增大的数值约束，红色选区不能被误读为火险升高。

`dev` 将整片平移替换为固定地理范围内的等值带翻腾：每一层颜色边界受连续空间扰动并外扩、渐隐，事件中心、手柄和天气符号位置保持固定。方向控件移除，仅保留 Cloud activity；0 表示可见的静态初始帧。默认六个半秒关键帧、半秒透明停顿、三秒循环。外扩纹理增加透明边缘留白，范围示意与预测输入掩膜分开。

参考视频 `example_figs/app_weather.mp4` 已实际解码并比较多个时刻；实现参考的是边界/强度团块变化，固定中心是本次指定约束。

## 公式审查：已实装的部分

输入依据为项目提供的 `DERIVATIVE_INFORMED_METHOD.md` §4，并重新查看下列原始论文/作者代码。当前发布包提供占用分数，尚无私有 raw logits、导数或逐格气象/燃料输入，因此本次交付的准确名称是：**文献机制约束 + 待校准的发布分数情景桥接**，而不是已完成导数定标的因果模型。

| 事件 | 本轮落地 | 仍有假设的环节 |
|---|---|---|
| 大风 | 使用经典 CFFDRS 的 `Δln fW = 0.05039 ΔW(km/h)`，准确换算 mph；移除统一 Rothermel 指数与旧软限幅的混搭。10→20 mph 的指数比为 2.250041。 | 10 mph 参考风和 κ=0.25 是公开的原型参数；发布分数门控不是测得的燃料干燥度。不是 R2/R4 定标结果。 |
| 降雨 | 雨量按实际重叠时长守恒分配；使用 FFMC 的 0.5 mm 截留、>150% 修正及 250% 上限，再经过 `f(F)` 比值。按 1/10/100 小时记忆做均匀润湿区间的指数积分和后续恢复。 | 初始含水率 16%、组分权重 0.5/0.35/0.15、占用耦合 0.35 是情景假设；不冒充有 T/RH/W 输入的完整日/小时 FWI 运行。截留按一次情景雨过程累计。 |
| 雷击 | 使用和为 1 的及时/潜伏核，避免旧核重复放大暴露；`pL=1-exp(-λ)` 后与调制后的基线作独立来源并集。降水条件在放电暴露发生时计算，而非事后重写过去的暴露。 | 覆盖率→有效暴露、λ幅度 0.04、野外存活/发现率和区内核形状待拟合。约 15% 潜伏比例仅是美国西部研究的情景参考，非全国常数。未把实验室每次放电概率直接用于野外火灾。 |
| 飓风 | 从轨迹逐段求移动速度和朝向，使用 Rankine 内/外风廓线计算当地风，避免整个风圈都用中心最大风；风走同一风链。雨/对流采用独立的移动径向区域，不再由是否存在 R34 决定能否降雨。修复弱风登陆衰减可能抬高到背景风的边界问题。公共轨迹陆上段采用现有 Kaplan–DeMaria 背景风/纬度参数。 | 径向雨区仍是假设的情景半径，并非已拟合 R-CLIPER；低于 34 kt 的空间支持用径向原型回退。近海慢衰减仍是视觉/情景设计。倒木通道尚无可用输入。 |
| 计划烧除 | 改为处理/未处理面积混合：`p1=(1-f)p0+f p_treated`，处理比例与空间掩膜、龄期分别起作用。0 处理精确恒等，增加处理比例不会增加分数。 | 处理后相对 log-odds 位移 −2 与 8 年半衰期仍是原型参数，**不再将其描述为元分析推导值**。没有把严重度降低 62–72% 等同于占用概率降低。 |

这些 `p` 是现有占用分数上的算术代理。对已发布/封顶分数取 logit **不能**恢复模型原始 logit；本轮未逆推出封顶后的私有值。

## 本次重新核对的来源

1. 经典 FWI/FFMC：加拿大林务局公式的[作者包代码 ffmcCalc](https://rdrr.io/rforge/cffdrs/src/R/ffmcCalc.R)、[ISIcalc](https://rdrr.io/rforge/cffdrs/src/R/ISIcalc.r)。核对了雨水截留、湿润修正、含水率上限及风/细燃料项。本次实现属于经典系统，不混用 FWI2025 与 FBP1992；[开发团队也提示两者暂不应直接组合](https://github.com/nrcan-cfs-fire/cffdrs-ng)。
2. FBP：[ROScalc 作者代码](https://rdrr.io/rforge/cffdrs/src/R/ROScalc.r) 已能读到 `b/c`，不是仍然缺表。例如 C1 为 0.0649/4.5，C2 为 0.0282/1.5。混合木、草地、C6 等存在专门条件，不能把通用曲线无条件用于全部燃料。缺的是本项目燃料类别映射与逐格输入，所以本轮没有自动套 FBP 类别响应。
3. [Latham–Schlieter 1989 原文](https://www.frames.gov/documents/behaveplus/publications/Latham_and_Schlieter_1989_INT-RP-411_ocr.pdf)：已下载并目视核对物理第 4/5 页的表 2/3。系数实际可取得；短针叶腐殖质深度、长针叶含水率、持续电流时间等输入与适用域才是约束。不能把实验室点火当作已发现野外火灾。
4. [Kalashnikov 等 2023 原文](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2023GL103785)：核对及时/2–5 天潜伏差异及地域依赖。本轮只采用守恒的双通道设计，不把组内时序权重当作论文拟合。原文提供的数据入口为 [Zenodo 7761326](https://doi.org/10.5281/zenodo.7761326)。
5. [Davis 等 2024 林务局原始出版记录](https://research.fs.usda.gov/treesearch/67659)：结局量是后续野火**严重度**，不是火点占用；不同处理组合与龄期不能直接反推统一占用半衰期。该文 DOI 是 **10.1016/j.foreco.2024.121885**，与输入资料中的 121859 不同。
6. 飓风几何/衰减沿用本项目已记录的源公式与数值基准，另加入弱风不增强、眼墙峰值与轨迹局部方向检查；不能把这些回归测试说成新的观测验证。原型近海衰减与降雨半径仍单独标注。

## 请和老师、Yangshuang 讨论的待补项

### 1. 模型端与发布变换

需要同一检查点/同一 issue 下的 R1、R2–R5、R9：raw logit、风/干燥度方向导数及有限差分曲线、燃料类别成对替换与出处元数据。用这些量定标 κ 或直接做 paired perturbation，再让 baseline/scenario 经过同一个发布变换。逐格 raw 值和导数保持服务端，不要求在静态前端公开。需要确认现有后端如何提供这个结果接口。即便拿到 R9，静态燃料类别的时间替换仍属模型外推；U-Net 的邻域响应也不能被当作逐格独立因果导数，需要一起检查扰动方向和训练支持集。

### 2. 雨与燃料

需要逐格初始燃料湿度、T/RH/风和燃料类型/组分，才能替换固定 16% 与记忆权重，或验证资料提出的“等价露点扰动”。FWI/FBP/FBFM40 跨系统映射需要明确批准。雨后 1–5 天的独立 HRRR/MRMS–FIRMS 验证仍需实施。

### 3. 雷击的野外桥接

需要覆盖档位与面积/时长对应的有效云对地放电数、燃料湿度/腐殖质深度、CG 与 GLM 的区别，以及存活/发现率。GLM 与 FPA-FOD/WFIGS 的配对验证决定可否采用风敏感度分级，不能先假定它等于闪电点火敏感度。当前四个发布窗口只到 +48 h，不能凭空展示 2–5 天的已发布基线；较长尾核目前只用合成输入检验时序。

### 4. 烧除、倒木与飓风雨区

需要燃料前/后类别成对模型响应与尺度匹配，确定严重度→占用的桥接是否成立、处理类型和龄期如何分层；8 年不是已验证通用半衰期。飓风还需要 R-CLIPER 雨带参数/验证及风后倒木燃料变化，才能替换现有径向雨区、加入长期倒木效应。

### 5. 验证与对外口径

请在看结果前确认符号/曲线/排序/跨地区留出和随机化检验标准，并确认派生分级披露政策。当前交付通过的是数学、因果时序、空间局部性和界面回归；它们分别支持实现正确性，不等同于实测火险预测技能或因果效应验证。
